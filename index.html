자주 묻는 질문

은퇴 시뮬레이터를 이용하시기 전 궁금한 점을 해결해 드립니다.

Q1. 은퇴 자산 진단 서비스는 유료인가요? +
SOMEMORE의 시뮬레이터 서비스(1단계, 2단계, 3단계)는 100% 무료로 제공됩니다. 광고 노출을 최소화하여 시니어 세대가 편안하게 노후를 가늠해 보실 수 있도록 기획되었습니다.
Q2. 제가 입력한 자산과 부채 정보가 해킹되거나 노출될 염려는 없나요? +
본 서비스는 서버가 없는 순수 브라우저 연동 방식입니다. 사용자가 입력한 자산 규모, 나이, 부채는 개발사나 외부 데이터베이스에 일절 전송되지 않으며, 사용자 브라우저의 내부 저장소(localStorage)에 격리 저장됩니다. 개인정보 수집 행위가 차단되어 안심하고 이용하셔도 됩니다.
Q3. 전세보증금도 부채로 입력해야 하나요? +
네, 그렇습니다. 세입자에게 언젠가 돌려줘야 할 전세보증금은 은퇴 시점에 반드시 갚아야 할 '부채'로 분류해야 미래의 여유자금이 과대계산되는 오류를 막을 수 있습니다. 1단계 부채란 또는 3단계 부동산 카드에 보증금 규모를 꼭 기재해 주세요.
Q4. 1단계 결과에는 왜 그래프가 안 나오나요? +
1단계(초간단 진단)는 사용자의 자산 세부 구조(부동산 비율, 주식 여부 등)와 개별 연금 가치를 모른 채 대략적인 평균 비율로 연산하므로, 긴 기간의 연도별 자산 변동 그래프를 제공할 경우 정보 오해 소지가 큽니다. 보다 정확한 흐름을 차트로 보시려면 2단계(정밀) 또는 3단계(심층)로 이어서 진단하시길 적극 권장합니다.
Q5. 단계를 올리면 처음부터 다시 입력해야 하나요? +
아닙니다. 1단계에서 입력한 나이·자산·소득·지출 정보는 2단계로 이어갈 때 자동으로 이어받아 채워집니다. 2단계에서 추가한 자산 분류·항목별 소득/지출 정보도 3단계로 이어갈 때 그대로 유지됩니다. 처음부터 다시 시작하지 않아도 되니 부담 없이 단계를 올려 더 정밀하게 진단해 보세요.
Q6. 국민연금도 월 소득으로 입력해야 하나요? +
네, 반드시 포함해 주세요. 국민연금은 물가상승률에 연동되어 매년 조금씩 오르는 가장 안정적인 은퇴 소득입니다. 2단계부터는 소득 항목별로 물가 연동 여부(📈 토글)를 따로 지정할 수 있으니, 국민연금 항목에 연동을 켜두시면 더욱 현실적인 결과를 얻을 수 있습니다.
Q7. 시뮬레이션 결과를 저장하거나 공유할 수 있나요? +
입력한 데이터는 사용 중인 기기의 브라우저에 자동 저장되므로, 앱을 닫고 다시 열어도 이어서 하기 기능으로 결과를 다시 볼 수 있습니다. 다른 기기나 배우자와 공유하려면 해당 기기의 브라우저에서 처음부터 동일하게 입력하셔야 합니다. PDF 내보내기 기능은 현재 개발 중입니다.
Q8. 물가상승률을 몇 %로 설정하는 게 좋을까요? +
한국은행의 공식 물가안정목표는 연 2.0%입니다. 보수적으로 판단하고 싶다면 2.5~3.0%를 권장합니다. 최근 5년 평균 소비자물가 상승률이 3%를 넘는 해도 있었으므로, '안심 시나리오'는 2.0%, '위험 시나리오'는 3.0~3.5%로 두 번 비교해 보시는 것이 가장 좋습니다.
Q9. 배우자와 나이 차이가 많이 나는데 어떻게 입력해야 하나요? +
1단계 입력 시 본인 나이와 배우자 나이를 각각 입력하시면 됩니다. 시뮬레이터는 두 분 중 더 오래 생존하는 쪽을 기준으로 자산 고갈 시점을 계산하므로, 나이 차이가 큰 경우에도 올바른 결과를 제공합니다. 안전 기준 나이도 배우자가 더 젊다면 조금 더 높게(예: 100세 이상) 설정해 두시길 권장합니다.
Q10. 안전 기준 나이와 금액을 어떻게 정해야 할까요? +
안전 기준 나이는 "이 나이까지는 자산이 남아있어야 마음이 편하다"는 심리적 기준선입니다. 통계청 기준 한국 남성 기대수명 83세, 여성 87세를 감안하면 95~100세로 설정하는 것이 보수적으로 안전합니다. 안전 기준 금액은 '지금 기준으로 그 나이에 최소 이 정도는 남아있어야 안심된다'는 금액입니다. 예상 의료비·간병비를 감안해 최소 3~5억 원을 추천드립니다.
